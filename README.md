
# technical-support-cv

Responsive resume created as part of the challenges and lab assignments for the “Web Design and Client-Side Scripting” module of the Higher Diploma in Science in Computing (Artificial Intelligence/Machine Learning) program at [NCI](https://www.ncirl.ie/Courses/NCI-Course-Details/course/HDCOMPAI)

## Week 1 challenge

Using your knowledge of HTML and CSS, start to build a CV.

Your CV should have:

- A h1 showing your name
- A h3 showing your email address and contact details
- h2 should be used for each section heading (Education, Experience, Skills)
- CSS should be used to change the background color and font color/family.

Extra:

If you are comfortable with all of the above, use W3 Schools to add:
HTML

- An unordered list of skills
- A link to a social media account

CSS

- Center all of the text of the page
