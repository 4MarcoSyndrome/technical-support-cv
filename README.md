
# technical-support-cv

Responsive resume created as part of the challenges and lab assignments for the “Web Design and Client-Side Scripting” module of the Higher Diploma in Science in Computing (Artificial Intelligence/Machine Learning) program at [NCI](https://www.ncirl.ie/Courses/NCI-Course-Details/course/HDCOMPAI)

## Week 1 challenge

Using your knowledge of HTML and CSS, start to build a CV.

Your CV should have:

- A h1 showing your name
- A h3 showing your email address and contact details
- h2 should be used for each section heading (Education, Experience, Skills)
- CSS should be used to change the background color and font color/family.

Extra:

If you are comfortable with all of the above, use W3 Schools to add:
HTML

- An unordered list of skills
- A link to a social media account

CSS

- Center all of the text of the page

## Week2 Challenge

Take the CV site you created last week and do the following:

- Use ID's and Classes to re-style your website.

You will need to go to W3 Schools to find out how to do the following:

- Add text shadow to your headings
- Underline and bold key words in your CV. You can use a span tag to target a specific word in a p tag or similar.
- Change the style of one of the lists on your page so that the bullet points appear differently
- Use HTML to create a link that when clicked jumps between headings on the page (you will need enough content on the page so that the user would need to scroll)

## Week3 Challenge

Update your CV from the last week to be a FlexBox responsive design. Design is mostly up to you but for full marks your design should:

- Have 3 columns at some point in the design
- Use Justified Content
- Use a media query to change some aspect of your design at smaller widths
